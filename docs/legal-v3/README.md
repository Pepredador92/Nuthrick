# Retirada de datos personales de las políticas públicas

Solicitud expresa del titular: 16 de octubre de 2026. Estos textos sustituyen los bloques de identificación particular de las versiones 2 y utilizan únicamente los contactos institucionales de Nuthrick ya verificados. El resto del contenido procede de las versiones vigentes de producción, no de las plantillas históricas.

La publicación crea las versiones 3, conserva las versiones originales y las aceptaciones en las tablas privadas y retira las copias anteriores de la proyección pública. Términos y Privacidad conservan el requisito de aceptación: el flujo existente solicitará aceptar sus nuevas versiones. No se registran aceptaciones en nombre de usuarios.

`publication.json` fija la versión, revisión y hash de origen para impedir sobreescribir una edición concurrente. `scripts/publish-legal-redaction.mjs` genera una operación SQL transaccional de contenido para revisión y ejecución por mantenimiento autorizado; no modifica el esquema ni suplanta una identidad administrativa. La auditoría distingue esa publicación operativa de una aprobación atribuida a una persona.

Esta retirada de información personal no certifica cumplimiento jurídico. Sigue pendiente resolver una identificación y un domicilio comerciales publicables: el artículo 15.I de la [LFPDPPP](https://www.diputados.gob.mx/LeyesBiblio/pdf/LFPDPPP.pdf) exige identidad y domicilio del responsable; el artículo 76 Bis.III de la [LFPC](https://www.diputados.gob.mx/LeyesBiblio/pdf/LFPC.pdf) contempla domicilio físico, teléfonos y otros medios de atención antes de una transacción de consumo. No se atribuye personalidad jurídica a la marca ni se publica un domicilio ficticio. Los datos particulares retirados no deben volver a copiarse a documentos públicos.

Publicación aplicada el 16 de octubre de 2026 en Supabase `qlsqhvyrslclmlstlemn`: tres versiones vigentes v3, cero copias públicas anteriores, seis originales privados conservados por su hash y doce aceptaciones anteriores intactas. Se registraron tres eventos de mantenimiento sin atribuirlos a una identidad humana. Los advisors de seguridad no añadieron hallazgos. Las pruebas locales verificaron transacción atómica, rechazo de origen desactualizado, retirada pública, historial, consentimientos, restricciones de edición e idempotencia; las seis pruebas frontend de Legal también pasaron.
